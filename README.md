# spyderWM
---
## A Wayland desktop shell for mangoWM using quickshell
---
Made with NixOS in mind at the moment, but the idea is to create a shell that's mostly widget based. So no traditional bar.
The default "bar" position will be vertical left. Planning on giving it a frosted glass look and use matugen for automatic 
color theming. 


This is my very first attempt, so this will take a while, i'm leaving the repo public to force myself to create and finish more projects.
